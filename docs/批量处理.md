# 批量处理（v3）

一句话：**选一个根目录，一句需求，对下面每个材料各生成一套新的 VASP 输入**。
两件事一次说清：

1. 同一个材料，扫多个参数（例如 IVDW 取 0 / 11 / 12）；
2. 多个材料，套同一句需求（例如都扩成 2×2×1、都加 D3(BJ)）。

## 怎么用

### 网页（推荐）

1. 双击桌面「VASP前处理」→ 切到 **批量** 页签；
2. 「批量根目录」选一个有子文件夹的目录，点 **扫描材料**（只读，不改文件）；
3. 写需求，例如：`扩成 2x2x1，加 DFT-D3(BJ)`；
4. 想要参数扫描就填 `0,11,12`（留空 = 只跑一遍）；
5. 点 **预览（不写文件）**：表里会列出每个材料、每个参数、**将要生成**的完整路径、原子数前后、改了什么；
6. 检查无误 → **全部写入**。

### 命令行

```bash
python -m vasp_core.batch --root D:\vasp_models --text "扩成 2x2x1" --ivdw 0,11,12
python -m vasp_core.batch --root D:\vasp_models --text "扩成 2x2x1" --ivdw 0,11,12 --write
python -m vasp_core.batch --root . --text "扩成 2x2x1" --json      # 给脚本用
```

不加 `--write` 就是预览，只打印目标和改动，不创建任何目录。

## 目录与命名（不用记，程序会显示）

```
vasp-prep-v2\batches\
└── <批次名>\
    ├── <材料名>\
    │   ├── POSCAR  INCAR  KPOINTS  INCAR.diff  change_report.md
    │   └── ivdw_11\   ← 只有做了参数扫描才出现
    │       └── 同上
    ├── batch_summary.csv    ← 一行一项，Excel 直接打开
    └── batch_report.md      ← 人看的总结
```

- **批次名**：你填（中英文/数字/空格/`- _ .`，≤60 字）；留空 = `batch_20261109-2115_2x2x1`（日期-时间 + 从需求里抠的关键词）。
- **材料名**：取材料文件夹名；非法字符换 `_`；重名自动 `_2`。
- **参数子目录**：`ivdw_<值>`（只对参数扫描生效）。
- 同名批次已存在 → 自动 `<批次名>_2`，**不会覆盖**旧结果；单项目标已存在 → 该项 `skip`，加 `--force` 才覆盖。

## 规则（为什么这么设计）

- **材料优先**：先按材料分，再按参数分——人找"MoS2 的结果"时不用先想参数。
- **同一句需求只理解一次**：模型/规则先对第一个材料出模板，再套到所有材料，保证批量内一致，也省时间。
- **每个材料单独试算**：任何一个材料失败（缺 POSCAR、原子数不够、参数非法），只标红那一项，其余照常，不会整批作废。
- **源目录只读**：只读 POSCAR/INCAR/KPOINTS，不写、不改 mtime；输出全在新目录。
- **上限**：材料 ≤ `max_materials`（默认 200），材料×参数 ≤ `max_dirs`（默认 500），防止误选整块盘。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 扫描到 0 个材料 | 子文件夹里没有 `POSCAR`/`CONTCAR` | 每个材料一个文件夹，里面放 POSCAR |
| 某项标红「第 3 个原子越界」 | 这句需求带序号，但该材料原子数不够 | 去掉序号，或对该材料单独处理 |
| 某项标红「IVDW=99 非法」 | 参数写错 | 用 0/1/2/11/12/13/20/202 等合法值 |
| 目标已存在 | 之前跑过同名批次/同名材料 | 接受 `skip`，或换批次名，或 `--force` |
| 想放到 D 盘 | 默认在仓库 `batches\` | 改 `vasp-prep.toml` 的 `[paths] batches_dir` |

## 与单文件的区别

| | 单文件 | 批量 |
|---|---|---|
| 输入 | 一个含 POSCAR 的目录 | 一个根目录，下面多个材料目录 |
| 理解 | 每次点预览都理解 | 只理解一次，套到所有材料 |
| 输出 | `runs\<名称>\` | `batches\<批次>\<材料>\...` |
| 参数扫描 | 一句话里写一个值 | `--ivdw 0,11,12` 自动展开 |
