# 数据库下载与导入（v4）

目标：把文献/数据库里的结构变成 **POSCAR**，放进 `materials\`，然后可以直接拿它当批量处理的根目录。

## 一页速查

| 数据源 | 能不能直接下 | 怎么做 |
|---|---|---|
| Materials Project | ✅ 免 API key | 网页「数据库」页 → 选 MP → 填 `MoS2` → 检索 → 下载 |
| OQMD | ✅ 免 key（较慢） | 同上，选 OQMD |
| AFLOW | ⚠ 只给页面链接 | 检索到后点「打开页面」，在官网下载后走「导入」 |
| 2Dmatpedia | ⚠ 首次下载整库缓存 | 检索可查；结构请官网按 id 下 CIF 再导入 |
| C2DB | ❌ 无公开 API | 官网导出 JSON/CIF → 「导入」 |
| ICSD / Materials Cloud / 中科院二维铁电库 | ❌ 需登录/内网 | 自己导出 CIF/POSCAR/zip → 「导入」 |

> 单独强调：ICSD 是订阅库，程序**不**替你绕过登录或抓取；你导出什么，它转什么。

## 命令行

```bash
# 检索（不写文件）
python -m vasp_core.db search --provider mp --formula MoS2 --limit 10

# 下载一条（写到 materials\mp_mp-2815\POSCAR）
python -m vasp_core.db download --provider mp --id mp-2815

# 放到子文件夹（materials\二维材料\mp_mp-2815\）
python -m vasp_core.db download --provider mp --id mp-2815 --subdir 二维材料

# 导入本地导出的 CIF/POSCAR/zip（文件或整个文件夹）
python -m vasp_core.db import --path D:\exported\c2db
```

所有命令都支持 `--json`，方便接脚本。

## 下载后的目录长什么样

```
materials\
└── mp_mp-2815\
    ├── POSCAR        ← 已转成分数坐标、按元素分组
    └── SOURCE.json   ← 来自哪个库、哪个 id、URL、时间、许可
```

`SOURCE.json` 的用途：半年后你能答出"这个结构哪来的、当时按什么条件查的"。
**批量处理直接选 `materials\` 作根目录即可**，它下面每个子文件夹都有一个 POSCAR。

## 为什么 MP/OQMD 能免 key

两家都提供公开的 [OPTIMADE](https://www.optimade.org/) 端点，返回字段里直接有
晶格矩阵、笛卡尔坐标、每个原子的元素——足够写 POSCAR。
程序按这个顺序取数：

1. 先按 `chemical_formula_reduced="MoS2"` 精确查；
2. 查不到再按 `elements HAS ALL "Mo","S"` 宽查，然后用 Hill 化学式二次过滤（去掉 MgMo2S2… 这类）。

坐标换算：`cart = frac @ L` ⇒ `frac = cart @ L⁻¹`，写成 VASP 的 `Direct` 坐标。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `连不上数据库` | 网络/代理/超时 | 换网络；OQMD 慢属正常，`[db] timeout` 可调大 |
| `数据库返回 HTTP 403` | 请求被拒 | 换 MP 试；或浏览器打开链接手动下 |
| `AFLOW 直链不可用` | 官网 `$files(POSCAR)` 当前返回空 | 用「打开页面」手下，再导入 |
| `导入 CIF 需要 pymatgen` | 当前解释器没装 | 用 `chgnet_env\python\python.exe` 启动网页（自带 pymatgen） |
| 下载目录已存在 | 之前下过 | 默认跳过；`--force` 覆盖 |
| 想换下载位置 | 默认在仓库 `materials\` | 改 `vasp-prep.toml` 的 `[paths] materials_dir` |

## 边界（别误会）

- 检索/下载**只取结构**，不带计算设置；INCAR/KPOINTS 仍由前处理按需生成。
- 不校验结构物理合理性（是否稳定、是否磁性有序），也不替你做去重。
- MP 数据许可为 CC BY 4.0，发表时请按其要求引用；`SOURCE.json` 里已记来源。
