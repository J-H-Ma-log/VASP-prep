# 网页使用说明（本地 VASP 前处理）

> 全程只在这台电脑上跑；不开端口到外网；不算能量、不改源文件。

---

## 1. 启动

**最简单：双击**

```
vasp-prep\启动网页.bat
```

它会：找解释器（优先 `..\chgnet_env\python\python.exe`，没有就用系统 python）→
启动服务 → 0.6 秒后自动打开浏览器 `http://127.0.0.1:8765`。

**手动启动（看日志用）**

```powershell
cd "C:\Users\28476\Desktop\Deepseek Harness\科研\vasp-prep"
..\chgnet_env\python\python.exe webui_launcher.py
```

看到 `[webui] http://127.0.0.1:8765` 就是成功了。关掉黑窗口 = 停服务。

> 为什么是 `webui_launcher.py` 而不是 `-m vasp_core.webui`：
> `chgnet_env` 是嵌入式 Python，`sys.path` 被钉死、不认当前目录和 `PYTHONPATH`；
> 运行 .py 文件时脚本目录会自动进 `sys.path[0]`，这是唯一稳的方式。

## 3. 一次完整操作（以 Cu 为例）

1. **源目录**点「选择…」用资源管理器选 `D:\work\cu`（里面有 `POSCAR`，可带 `INCAR`/`KPOINTS`），或直接粘贴路径；
   过程区会告诉你：几原子、元素、晶格、体积、有没有 INCAR/KPOINTS。
2. **输出名称**：结果固定写到 `vasp-prep\runs\<名称>\`。留空 = `<源目录名>_out`；想叫别的就自己填（中英文、数字、`- _ .` 都可以，不能有 `\ / : * ? " < > |`）；同名会自动加 `_2`，不会覆盖旧结果。
3. **需求**用一句中文写，例如：
   - `扩成 2x2x1，第 3 个原子换成 Co，ENCUT 调到 520`
   - `删掉第 5 个原子，真空层加到 15 埃`
   - `把所有 Cu 换成 Ni，K 点 6x6x1`
4. 点**预览**：等 2–5 秒，出现过程时间线 + 摘要 + diff。
5. 看 diff 没问题 → 点**写入** → `runs\<名称>\` 里出现：
   `POSCAR`、`INCAR`、`KPOINTS`（源里有就复制）、`INCAR.diff`、`change_report.md`、`recipe.json`。
6. 打开 `change_report.md`，确认"结构变化 / INCAR 变更 / 检查结果"三节，再拿走目录。

> 预览和写入用的是**同一份配方**：预览看到的 diff 就是写出来的内容，
> 不会出现"预览一套、写入另一套"。

## 4. 接模型（三种选择）

### A. 本地 Ollama（推荐，默认）

```powershell
ollama serve                 # 已常驻可跳过
ollama pull qwen2.5-coder:7b # 约 4.7 GB
ollama list                  # 确认有 qwen2.5-coder:7b
```

程序默认就去 `http://127.0.0.1:11434/v1` 找它；右上角显示"在线（xx ms）"即可用。

### B. 云端 OpenAI 兼容接口

改 `vasp-prep.toml`：

```toml
[llm]
enabled = true
base_url = "https://你的服务/v1"
model = "你的模型名"
api_key = "sk-xxx"
privacy = "strict"     # 只发指令和摘要，不发结构文件
```

### C. 完全不用模型

```toml
[llm]
enabled = false
```

此时只走规则模式：扩胞、替换、空位、真空、ENCUT、K 点、应变、批量换元素都能用；
"切表面/加吸附质"会提示需要更明确的说法。

## 5. runs\<名称>\ 里每个文件干什么

| 文件 | 内容 | 你该看什么 |
|---|---|---|
| `POSCAR` | 改好的结构（元素行 + 计数 + 坐标） | 元素顺序、原子数 |
| `INCAR` | 改好的参数（保留原注释和顺序） | 与 `INCAR.diff` 对照 |
| `KPOINTS` | 源目录有就原样复制；没有则按配方生成 | 网格是否够 |
| `INCAR.diff` | unified diff，只有 INCAR 有改动时才有 | 每一行 `-`/`+` |
| `change_report.md` | 结构变化、操作清单、INCAR 变更表、检查结果、下一步 | 先看"检查结果"里的 WARN |
| `recipe.json` | 这次"理解成的作业单"，可手改后命令行复用 | 想微调时改它 |

**不会生成 POTCAR**：POTCAR 与赝势库、版权、元素变体有关，由你在超算上按
`POSCAR` 第 6 行的元素顺序拼（`cat Cu/POTCAR Co/POTCAR > POTCAR`），
并用 `grep TITEL POTCAR` 核对。

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击后黑窗口闪退 | 解释器没找到 / 报错 | 在黑窗口里看最后一行；用命令行启动看完整报错 |
| 浏览器打不开页面 | 端口被占用（服务会自动换到 8766…） | 看黑窗口打印的实际地址；或改 `[ui] port` |
| 右上角"离线，已用规则模式" | Ollama 没起 / 模型没拉 | `ollama serve`、`ollama pull qwen2.5-coder:7b`，点"重试连接" |
| 提示"没有 pymatgen" | 用了系统 Python | 用 `启动网页.bat`（自动找 chgnet_env）；或只做非切面操作 |
| "目标目录已存在" | 防覆盖 | 换新目录；确实要覆盖就命令行加 `--force` |
| 需求被标"需要人确认" | 切表面/固定层/DFT+U 等 | 按提示写更明确的说法，或直接改模板 |
| 预览很慢（>30 s） | 模型首次加载进显存 | 第一次 3–10 s 正常；持续慢就换 3B 或关模型 |

## 7. 安全设计（为什么敢让它写文件）

1. **只写新目录**：输出目录已存在 → 拒绝；源目录 → 永不写入；
2. **白名单**：INCAR 只允许 19 个键；`LDAU*`、`NELECT`、`LHFCALC`、泛函等 12 个危险键一律拒绝；
3. **先预览后写入**：写入按钮在预览成功前是灰的；写入还要再确认一次；
4. **可回退**：源目录不动；写错了删掉输出目录即可；每次操作有 `recipe.json` 可复现；
5. **模型不算数**：模型只提建议，配方必须过 schema、边界、一致性三道校验；
6. **不联网**：服务只监听 `127.0.0.1`；模型调用只发指令和摘要。


### 2.1 「选择…」按钮怎么工作

点「选择…」→ **后端**在你的桌面上弹出 Windows 原生的"选择文件夹"窗口（不是网页里的假弹窗）→ 选完自动填回输入框。

- **源目录**：选哪个文件夹就是哪个，选完可以点「预览」直接看结构摘要；
- **输出名称**：结果固定写到 `runs\<名称>`；名称可以自己起，源目录名只是默认值；
- **取消**：窗口点"取消"或按 Esc → 页面提示"已取消选择"，不报错；
- 弹不出来（禁用了 PowerShell、没有桌面会话）→ 页面会显示具体原因，而不是假装你取消了。

> 为什么不让浏览器直接选：浏览器出于安全限制拿不到文件夹的**绝对路径**，只能拿到文件名，
> 后端弹原生窗口是唯一能拿到真实路径的办法。
## 色散修正（IVDW）

组里 INCAR 里常见的 `IVDW` 现在支持了，规则是"**你点名才改**"：

| 你写 | 变成 |
|---|---|
| 加 DFT-D3 修正 / 加 D3 | `IVDW = 12`（D3-BJ，最常用） |
| D3 零阻尼 | `IVDW = 11` |
| 加 D2 | `IVDW = 1` |
| 加 TS | `IVDW = 20` |
| 加 MBD | `IVDW = 202` |
| 加 D4 | `IVDW = 13` |
| 直接写 IVDW=11 / IVDW 设为 11 | 按数值 |

- 只写 `IVDW = N` 这一行；源 INCAR 里本来有 IVDW（比如 11）就只改那一行，其余不动。
- 只说"加色散校正"但没说哪种方法 → 会列入"需要你决定"，不猜。
- 13 / 14 / 15 需要 VASP 编译了外部包，会提示你确认。
- 模型自己往里塞 IVDW 会被丢弃（日志会写一条 warn）。
## 报错处理：`PermissionError [WinError 5] 拒绝访问`

现象：预览能成功，点"写入"时报 `PermissionError: [WinError 5] 拒绝访问。: '...\MoS2_out'`。

这不是配方或结构的问题，是**Windows 不让这个 Python 进程在那个位置建目录**。按下面顺序排查：

1. **把输出目录留空**（最稳）。留空时程序写到自己的 `runs\<源目录名>_out`，这个位置一定有写权限；写完再从资源管理器挪到你要的地方。也可以改成非桌面目录，如 `D:\vasp_runs` 或 `C:\Users\<你>\vasp_runs`。
   `C:\Users\28476\vasp_runs`（选父文件夹，程序会自己在里面建 `<源目录名>_out`）。
   桌面/文档常被"受控文件夹访问"或杀软保护，换盘往往立刻好。
2. **确认启动方式**。关掉所有黑窗口，回到**资源管理器**里双击 `启动网页.bat`；
   不要从别的工具/终端里启动（受限环境只能写自己的工作区）。
3. **跑自检**。双击 `检查写入权限.bat`，它会打印：
   当前 pid/用户/工作目录，以及对 `仓库`、`桌面\test`、`桌面\test\MoS2test`、
   `C:\vasp_runs`、临时目录 的"建目录+写文件+删除"结果。
   把这段结果发我，就能确定是权限、杀软还是启动方式。
4. **看是谁在跑**。浏览器打开 `http://127.0.0.1:8765/api/status`，
   看 `runtime` 里的 `pid/cwd/python`：如果 `cwd` 不是 `vasp-prep`，
   说明浏览器连到了一个旧的/别的服务，关掉重开。

程序侧也做了改进（重启后生效）：
- 写入前先自检父目录，失败时给中文原因（含 pid/用户/工作目录/三条常见处理）；
- `/api/status` 多返回 `runtime` 字段；
- 新增 `检查写入权限.bat` + `tools\check_write.py`。
## 运行模式：受限 / 普通（只影响"能不能写别处"，不影响出结果）

网页启动时会自检，顶部徽章会显示：

| 徽章 | 含义 | 说明 |
|---|---|---|
| 普通模式（Medium） | 从资源管理器/桌面快捷方式启动 | 有完整权限；输出仍在 `runs\` |
| 受限环境（Low） | 进程被沙箱降权 | 仍能正常出结果，只是只能写 `runs\` |

**为什么会受限**：这个进程是从"受限终端/受限环境"里启动的，操作系统只给了它工作区的写权限。
不是 Windows 不让你写桌面，也不是 Python 没权限，提权（管理员）也解决不了——要换启动方式。

**怎么变成普通模式（不用命令行）**：

1. 关掉当前黑窗口；
2. 双击 `创建桌面快捷方式.bat`（只做一次，它调用 `tools\make_shortcut.ps1`），桌面会出现「VASP-Prep」图标；
3. 以后每次双击桌面图标启动 —— 这就是普通权限，徽章会变成"普通模式"，输出目录可以随便选。

如果徽章仍是"受限"，说明你是从别的工具里双击的启动脚本；请用 `Win+E` 打开资源管理器，
进入 `vasp-prep` 文件夹，直接双击 `启动网页.bat`。

## 8. 批量页（v3）

顶部页签切到 **批量**：

1. **批量根目录**：选一个目录，它下面每个子文件夹里各有一个 `POSCAR`（例如 `D:\vasp_models\MoS2\POSCAR`、`D:\vasp_models\WS2\POSCAR`）；
2. 点 **扫描材料**：只读，列出找到几个、哪些读不了；
3. **需求**写一句（同一句套到所有材料上）；
4. **批次名称**可留空（自动 `batch_日期-时间_关键词`）；
5. **参数扫描**填 `0,11,12` 就是"每个材料都做这三份 IVDW"，留空 = 只做一遍；
6. **预览** → 表里看"将要生成"的完整路径与改动 → **全部写入**。

结果在 `vasp-prep\batches\<批次>\...`，点顶部「查看 batches」直接打开。
命名规则、上限、排错见 `docs\批量处理.md`。

## 9. 数据库页（v4）

顶部页签切到 **数据库**：

1. 选库（MP / OQMD 免 key；AFLOW 给链接；2Dmatpedia 走整库缓存）；
2. 填化学式（`MoS2`）→ **检索**；
3. 能直接下的行点 **下载**，落到 `materials\<库>_<id>\POSCAR`；
4. 本地导出的 CIF/POSCAR/zip 用底部 **导入**（ICSD、Materials Cloud、中科院二维铁电库都走这里）。

下载目录自带 `SOURCE.json`（来源/URL/时间/许可）；也可以直接把它当批量根目录。
细节见 `docs\数据库下载.md`。

## 10. 顶部「查看 runs / batches / materials / imports」

这四个按钮不用记路径：程序自己知道目录在哪，点一下就打开资源管理器；
目录不存在会先建好再打开。受限模式下也能打开（只读查看没问题）。

补充：**受限模式点「查看 xxx」会发生什么**——系统不允许受限进程启动资源管理器，
所以按钮不会弹窗口，而是在按钮下方展开一个**网页内的目录列表**：
文件夹可点进去看、能复制当前路径、能返回上一级。
想恢复"真的弹资源管理器"，从桌面快捷方式（普通完整性）启动即可；受限时也能看结果，只是不能一键弹出。
