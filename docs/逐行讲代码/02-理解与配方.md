# 02 理解与配方：nl.py / recipe.py 逐行讲解

对应文件：

- `vasp_core\nl.py`（373 行）—— 不依赖模型的中文 → 配方规则翻译器（"第一层听懂"）
- `vasp_core\recipe.py`（327 行）—— 配方 schema、严格校验、结构操作的执行顺序

两者中间是 `service.compose_recipe`（见 `05` 的 1.14 与本节末尾补讲）：

```text
用户一句话
   │
   ├─ service.understand ──► 模型在线？ ── 是 ──► llm.text_to_recipe（JSON）
   │                              └─ 否/失败 ──► nl.text_to_recipe（规则）
   ▼
service._finalize_recipe（补 version/name/base_dir/structure）
   ▼
service._apply_calc_policy（calc/preset/丢弃擅自加的 IVDW）
   ▼
prep.run ──► recipe.load_recipe（严格校验）──► recipe.apply_ops（顺序执行）
```

> 行号是文件真实行号；"代码"去掉行首缩进，但标识符与原文一致。
