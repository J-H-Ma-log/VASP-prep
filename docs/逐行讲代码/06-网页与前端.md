## 逻辑树（先看这张）

> 一次点击从浏览器到 Python 再回来。向下 = 调用/数据流；路由都在 `Handler.do_GET` / `do_POST` 里分发。

```text
浏览器（web/index.html）
   │  按钮 onclick ──► JS 函数 ──► fetch("/api/...")
   ▼
webui.Handler.do_GET / do_POST
   ├─ GET  /api/status        ──► llm.probe 探活 + runtime_mode / integrity_level
   ├─ GET  /api/browse        ──► browse.pick_directory（系统弹窗选目录）
   ├─ GET  /api/open          ──► _open_folder（explorer；受限时返回 opened:false）
   ├─ GET  /api/ls            ──► 只列一层目录（网页内兜底浏览）
   ├─ POST /api/preview       ──► service.preview
   ├─ POST /api/write         ──► service.write（必须 confirm=true）
   ├─ GET  /api/batch/scan    ──► batch.scan_materials
   ├─ POST /api/batch/preview ──► batch.preview_batch
   ├─ POST /api/batch/write   ──► batch.write_batch（confirm 必需）
   ├─ GET  /api/db/providers  ──► 写死的 provider 列表
   ├─ GET  /api/db/search     ──► db.search
   ├─ POST /api/db/download   ──► db.download
   └─ POST /api/db/import     ──► db.import_file / import_folder
   ▼
统一 JSON：成功 {ok:true, ...}；异常 {ok:false, error:"…"} + 4xx/5xx
   ▼
前端：renderLogs / renderSummary / renderDiffs / 表格重绘 / showError
```

### 1.4 逐行讲解：_can_write（112-121）

**干什么**：在目录 `d` 下真的建一个临时子目录再删掉，用「能不能建」判断进程有没有写权限。

### 1.14 逐行讲解：Handler.do_POST（350-435）

### 2.2 前后端契约

| 请求 | 前端怎么发 | 后端返回 | 页面怎么用 |
|---|---|---|---|
| `GET /` | 浏览器地址栏直接访问；不走 `api()` | `text/html`（`web/index.html` 原始字节） | 浏览器渲染页面 |
| `GET /api/status` | `api("/api/status")`，无参数 | `{ok, config, model, runtime}` | 两个徽标；`config.paths.default_source` 预填源目录 |
| `GET /api/browse?kind=source&initial=...` | `pickDir` / 批量选根目录 / 导入选目录；会一直等到用户关掉系统对话框 | `{ok, path, cancelled}`；取消时 `path=null` | 写回对应输入框；批量根目录选完自动 `batchScan()` |

| `GET /api/batch/scan?root=...` | `batchScan()`；不传 depth | `{ok, scan:{n_found,n_ok,materials,...}}` | `#scanLine` 显示「找到 N 个材料，可读 M 个」及名单 |
| `GET /api/db/providers` | 前端从未调用（下拉框的四个 option 是写死在 HTML 里的） | `{ok, providers:[{id,label,mode}]}` | 未使用；页面只展示 mp/oqmd/aflow/2dmatpedia 四个 |
| `GET /api/db/search?provider=&formula=&limit=20` | `dbSearch()` | `{ok, items:[{provider,id,formula,nsites,url}]}` | `renderDbResults` 画表；按 provider 给下载按钮或外链 |
| `POST /api/preview` | body `{source, name, text}` | `{ok, job}`（Job 含 `id/summary/diffs/logs/output/files` 等） | 日志、摘要、diff；`summary.ok` 决定写入按钮 |
| `POST /api/write` | body `{job_id, confirm:true}` | `{ok, job}`，`job.written=true` | 更新状态行、日志、摘要 |

| `POST /api/db/download` | body `{provider, id, formula}` | `{ok, path}` | 按钮变「已下载」，`#dbHint` 显示保存路径 |
| `POST /api/db/import` | body `{path}` | `{ok, paths:[...]}` | `#dbImportHint` 显示导入数量与目录名 |

错误约定：后端返回 4xx/5xx 时 body 是 `{ok:false,error:"..."}`；`api()` 据此 `throw`，调用方在 catch 里 `showError()` 并改状态行。`GET /` 缺文件是例外——返回纯文本 500。
