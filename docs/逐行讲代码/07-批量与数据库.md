## 0. 这两个模块怎么用、谁调用

- 网页端在 `webui.py:39` 把两个模块整个引入（`batch as batch_mod`、`db as db_mod`），前端所有批量/数据库操作都走路由：批量 3 个（`/api/batch/scan`、`/preview`、`/write`），数据库 4 个（`/api/db/providers`、`/search`、`/download`、`/import`：分别在 webui.py:289、364、383、323、333、395、407 起）。
- 批量：`scan`（webui.py:289-297）只读扫描；`preview`（364-382）在 `.tmp_service/batch_*` 里逐项试算、不写 `batches/`，结果放进内存字典 `_BATCH_JOBS`（`webui.py:57`，最多留 3 份，`_BATCH_KEEP=3`）；`write`（383-394）要求 `confirm=true`，取同一份预览结果调 `write_batch` 真正落盘。

- 命令行：`python -m vasp_core batch ...` / `python -m vasp_core db ...`，由 `vasp_core/__main__.py:43-49` 的 `COMMANDS` 分发到两个 `main`；两者都用返回码 0/2 表示成功/用户错误（`PrepError`）。

### 1.1 逐行讲解：find_materials（61-86）

**干什么**：在 `root` 下按层数找"含 POSCAR 的文件夹"。`root` 自己不算材料，只从它的子目录开始；每一层都只往下走 `depth+1` 层。
**参数**：`root`（str 或 Path，必填）；`depth`（int，默认 0）：0 只看 root 的直接子目录，1 再看一层，负数按 0 处理。
**返回**：`list[Path]`，每项是材料的绝对路径目录；顺序是"按层、层内按目录名排序"。
**异常**：`PrepError`——root 不存在或不是目录。`iterdir()` 的 `OSError` 被吞掉（该目录跳过）。
**谁调用**：`scan_materials`（96 行）；`tests/test_batch.py`。

| 行 | 代码 | 说明 |
|---|---|---|
| 61 | `def find_materials(root: str \| Path, depth: int = 0) -> list[Path]:` | 入口。docstring（62-68 行）解释了 depth 语义和"为什么不用 os.walk 全递归"：防止用户选到 home 目录时扫几万个无关目录。 |
| 69 | `root = Path(root).expanduser().resolve()` | 先用 `expanduser()` 展开 `~`，再 `resolve()` 变绝对路径（同时消掉 `..` 和软链接）。 |

| 72 | `found: list[Path] = []` | 结果列表。 |

| 74 | `for _ in range(max(0, depth) + 1):` | depth=0 → 循环 1 次（扫 root 的直接子目录）；depth=1 → 2 次；`max(0, …)` 保证负数也至少扫 1 层。 |

| 86 | `return found` | 返回收集到的目录。 |

### 1.4 逐行讲解：_keyword（141-161）

**干什么**：从需求文字里抠一个短关键词，拼进默认批次名，方便人认。例：`"扩成 2x2x1，加 DFT-D3(BJ)"` → `"2x2x1_d3bj"`。
**参数**：`text`（str，可以是空串）。
**返回**：str，多个关键词用 `_` 连接、总长截到 40；一个都没抠到 → `"edit"`。
**异常**：无。
**谁调用**：`make_batch_name`（169 行）。

| 行 | 代码 | 说明 |
|---|---|---|
| 141 | `def _keyword(text: str) -> str:` | 入口。docstring 142-146 行给了例子。 |
| 147 | `low = (text or "").lower()` | 空值兜底成 `""`；转小写是为了匹配 `d3/bj/zero` 这类英文（中文不受影响）。 |
| 148 | `keys: list[str] = []` | 关键词列表。 |
| 149 | `if m := re.search(r"\d+\s*[x×*]\s*\d+\s*[x×*]\s*\d+", low):` | 海象运算符 `:=`：匹配到就同时把 `m` 赋上。正则找"数字 x 数字 x 数字"，中间允许空格和三种乘号（字母 x、全角 ×、星号 *）。 |
| 150 | `keys.append(re.sub(r"\s*[x×*]\s*", "x", m.group(0)))` | 归一成 `2x2x1` 这种统一写法（去掉空格、乘号统一成字母 x）。 |
| 151 | `if "d3" in low and ("bj" in low or "零阻尼" not in low and "zero" not in low):` | 优先级：`and` 先于 `or`，所以条件是"含 d3"且（"含 bj" 或（"不含零阻尼"且"不含 zero"））。含义：没明确说零阻尼时，D3 默认按 BJ 记。 |
| 152 | `keys.append("d3bj")` | 记 `d3bj`。 |
| 153-154 | `elif "d3" in low:`<br>`keys.append("d3")` | 明确写了"零阻尼/zero"才会走到这里。 |
| 155-156 | `elif "d2" in low:`<br>`keys.append("d2")` | 没有 d3 才看 d2。 |
| 157-158 | `if "空位" in low or "vacancy" in low:`<br>`keys.append("vacancy")` | 独立的 `if`（不是 elif），所以可以和 d3 同时出现。 |

### 1.6 逐行讲解：_dedupe（172-183）

**干什么**：同一批次内材料重名时，按出现顺序改成 `原名`、`原名_2`、`原名_3`…**只算名字，不碰磁盘**。
**参数**：`names`（list[str]，已经过 `safe_name` 的名字列表）。
**返回**：list[str]，长度与输入相同。
**异常**：无。
**谁调用**：`plan_targets`（199 行）、`preview_batch`（255 行）。

| 行 | 代码 | 说明 |
|---|---|---|
| 172 | `def _dedupe(names: list[str]) -> list[str]:` | 入口。 |
| 174 | `seen: dict[str, int] = {}` | 记录"这个名字已经出现过几次"。 |
| 175 | `out: list[str] = []` | 输出。 |
| 176 | `for n in names:` | 按原顺序遍历。 |
| 177-179 | `if n not in seen:`<br>`seen[n] = 1`<br>`out.append(n)` | 第一次出现：计数记 1，名字原样保留。 |
| 180-182 | `else:`<br>`seen[n] += 1`<br>`out.append(f"{n}_{seen[n]}")` | 第二次出现 → `名字_2`，第三次 → `名字_3`。 |
| 183 | `return out` | **注意**：这里只避免"同一批输入内部"重复，不检查生成的 `_2` 会不会和输入里本来就有的名字撞（例如输入 `["Cu","Cu","Cu_2"]` 会得到 `["Cu","Cu_2","Cu_2"]`）。撞名后两个材料指向同一目标目录，写入时后一项会变成 `skip`。 |

```json
{
  "data": [
    {
      "id": "mp-999",
      "type": "structures",
      "attributes": {
        "lattice_vectors": [[3.0, 0.0, 0.0], [0.0, 3.0, 0.0], [0.0, 0.0, 10.0]],
```

## 3. 一次批量/一次下载的真实文件变化

以下路径默认配置下（`batches_dir="batches"`、`materials_dir="materials"`、`cache_dir="cache"`），`<批次>` 是自动或用户给的批次名，`<材料>` 是清洗后的材料文件夹名。

| 步骤 | 目录/文件 | 谁写的 |
|---|---|---|
| 批量预览（试算） | `.tmp_service/batch_<8位十六进制>/<0000..>/recipe.json` | `service.stage_recipe`（service.py:341-380） |
| 批量预览（试算产物） | `.tmp_service/batch_<…>/<0000..>/out/{POSCAR, INCAR, KPOINTS?, INCAR.diff?, change_report.md}` | `prep.run`（prep.py:156 起） |
